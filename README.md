# Anveshak — AI Research Assistant

> **Your Second Brain for Academic Excellence.**
> Accelerate your research cycle with advanced AI that can search, read, and synthesize scholarly papers with human-like precision.

---

## ✨ Overview

**Anveshak** is a full-stack AI-powered research assistant platform designed for academics, researchers, and students. It lets you upload, organize, and intelligently query a personal library of academic papers using natural language.

Key capabilities include:

- 🔍 **Semantic Search** — Find papers by meaning, not just keywords, using vector embeddings
- 💬 **Talk to Paper** — Chat with any paper using a Gemini-powered AI assistant
- 📚 **Literature Reviews** — Auto-generate synthesis reports across multiple papers
- 📊 **Compare Papers** — Side-by-side AI comparison of methodologies, findings, and gaps
- 🗺️ **Research Roadmaps** — Visual step-by-step research plans generated by AI
- 📁 **Collections** — Organize papers into named collections
- 🔐 **Authentication** — Email/password signup + Google OAuth2 sign-in

## 🏗️ Architecture

The project is a **monorepo** with three services:

```
anveshak/
├── backend/          # Spring Boot REST API (Java 21)
├── frontend/         # React + TypeScript SPA (Vite)
├── embeddingService/ # FastAPI embedding microservice (Python)
└── infra/            # Docker Compose for local infrastructure
```

### System Diagram

```
Browser (React/Vite)
        │
        ▼  REST (HTTP/JSON)
Spring Boot API  ─────► PostgreSQL + pgvector
        │                       ▲
        │  HTTP (embed)         │ (vector similarity search)
        ▼                       │
FastAPI Embedding Service ──────┘
(SentenceTransformers / all-MiniLM-L6-v2)
        │
        ▼
Google Gemini API  (paper chat, compare, literature review, roadmaps)
Supabase Storage   (PDF file storage)
```

## 🚀 Getting Started

### Prerequisites

- **Java 21+**
- **Node.js 20+** and **npm**
- **Python 3.11+**
- **Docker & Docker Compose**
- A **Google Cloud** project (for OAuth2 and Gemini API Key)
- A **Supabase** project (for PDF file storage)

---

### 1. Start Infrastructure (PostgreSQL + Embedding Service)

```bash
cd infra
docker compose up -d
```

This starts:
- **PostgreSQL 17** with `pgvector` on port `5436`
- **Embedding Service** on port `8001` (first run downloads the model — may take a few minutes)

> **Note:** The `pgvector` extension is enabled automatically by the Flyway migrations on first boot.

---

### 2. Configure the Backend

Edit `backend/src/main/resources/application.yml` or provide the following as environment variables:

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5436/anveshak_db
    username: <your_db_user>
    password: <your_db_password>

google:
  client-id: <your_google_oauth_client_id>

supabase:
  url: <your_supabase_rest_url>
  access-key: <your_supabase_anon_key>
  secret-access-key: <your_supabase_secret>
  service-role-key: <your_supabase_service_role_key>
  bucket-name: anveshak

jwt:
  secret: "<base64_encoded_secret>"
  expiration: 3600000        # 1 hour in ms
  private-key-file: 'path/to/private.pem'
  public-key-file: 'path/to/public.pem'

google-gemini:
  api-key: <your_gemini_api_key>

app:
  mail:
    from: no-reply@yourdomain.com
  base-url: http://localhost:8080
```

> ⚠️ **Never commit secrets to version control.** Use environment variables or a secrets manager for production.

---

### 3. Run the Backend

```bash
cd backend
./mvnw spring-boot:run
```

The API starts on **http://localhost:8080**.
API documentation (Scalar UI) is available at **http://localhost:8080/scalar/index.html**.

---

### 4. Run the Frontend

```bash
cd frontend
npm install
npm run dev
```

The frontend dev server starts on **http://localhost:5173**.

## 🔌 API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/auth/register` | Register with email/password |
| `POST` | `/auth/login` | Login, returns JWT |
| `POST` | `/auth/google` | Google OAuth2 login |
| `GET` | `/papers` | List all user papers |
| `POST` | `/papers` | Upload new paper (multipart PDF) |
| `GET` | `/papers/search?query=` | Semantic vector search |
| `POST` | `/papers/compare` | AI comparison of selected papers |
| `POST` | `/papers/literature-review` | AI-generated synthesis report |
| `GET/POST` | `/papers/{id}/chat` | Chat with a specific paper |
| `GET` | `/collections` | List all collections |
| `POST` | `/collections` | Create a new collection |
| `POST` | `/collections/{id}/papers/{paperId}` | Add paper to collection |
| `DELETE` | `/collections/{id}/papers/{paperId}` | Remove paper from collection |

Full interactive documentation: `http://localhost:8080/scalar/index.html`

## 🐳 Docker

The `infra/docker-compose.yml` manages local development dependencies:

```bash
# Start all services
cd infra && docker compose up -d

# Stop all services
docker compose down

# View embedding service logs
docker compose logs -f embedding
```

**Services:**

| Service | Port | Description |
|---------|------|-------------|
| `postgres` | `5436` | PostgreSQL 17 with pgvector |
| `embedding` | `8001` | FastAPI embedding microservice |
